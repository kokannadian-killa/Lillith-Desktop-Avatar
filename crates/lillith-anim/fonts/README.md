# Bundled fonts

- `NotoEmoji-Regular.ttf`: Noto Emoji (monochrome outline emoji, variable
  weight; default instance used), © 2013 Google LLC, licensed under the SIL
  Open Font License 1.1 (`OFL-NotoEmoji.txt`). Source: Google Fonts
  (github.com/google/fonts, `ofl/notoemoji`). Unmodified.

It is compiled into the binary (`lillith_anim::text::NOTO_EMOJI`) and used as
the emoji fallback for the overlay speech bubble and the egui chat window.
