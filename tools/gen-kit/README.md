# gen-kit
Fast path for new Lillith allure clips. Start with `GUIDE.md`.
- `make_clip.py`: list / prompts / build / check
- `prompts/character_lock.txt`, `prompts/avoid.txt`, `prompts/still_template.txt`, `prompts/video_template.txt`
- `prompts/recipes/*.json`: 8 pose recipes (prompt fields + build settings)
- `prompts/videoreview_qa.txt`: optional videoReview paste-in
