# Layered-art tools

See `docs/LAYERED_ART.md`.

- `build_idle_a_layers.py` — split the shipped `idle_a` sheet into base / covered-chest / pigtail layers. Defaults to the scratch tree used for this pilot; pass paths when re-running.
- `preview_layers.py` — zero-offset QA, seam check at 10/16 px, contact sheet, optional MP4/GIF.
